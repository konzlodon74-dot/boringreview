## The entry

> "The rubber band has one job -- hold things together -- so naturally it spends its whole life in a drawer drying out, and snaps the one time you actually need it."

## What it does

`main.py` writes that single line (plus a trailing newline) to `/output/entry.txt`. The joke is a true observation: rubber bands really do perish in drawers and snap exactly when you reach for one. Python 3, standard library only, no network, fully deterministic — repeated runs produce byte-identical output.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
